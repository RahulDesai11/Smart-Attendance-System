# AI Smart Classroom Attendance System

A Face Recognition Attendance System built using Python, OpenCV and DeepFace.

## Features

- Student Face Registration
- Face Embedding Generation
- Multiple Face Recognition
- Smart Attendance Ready
- FaceNet512 Model

## Tech Stack

- Python
- OpenCV
- DeepFace
- NumPy

## Project Structure

```
Dataset/
Trainer/
Input_Image/

capture.py
train.py
recognize.py
```
